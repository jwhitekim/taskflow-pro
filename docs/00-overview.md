## 왜 이렇게 나누는가
관심사 분리(Separation of Concerns) 원칙에 따라 문서를 나눈다. "왜 만드는가(01)", "무엇을 만드는가(02)",
"어떻게 만드는가(03)", "어떤 순서로 만드는가(04)", "어떤 규칙으로 만드는가(05)"를 각각 별개 문서로 분리하면,
한 문서를 수정해도 다른 문서에 영향을 주지 않고, 필요한 정보만 골라 참조할 수 있다. 예를 들어 API 스펙만
확인하고 싶을 때 02-specs.md만 읽으면 되고, 기술 선택의 이유가 궁금할 때는 03-design.md만 참조하면 된다.
